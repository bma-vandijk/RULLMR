Practical session files
=======================

Put notebooks, data, and environment files in this folder (optionally in a
subfolder per session), then commit and push. The Resources page lists every
file here except this README.

Suggested names:

  session-00-introduction/notes.ipynb
  session-00-introduction/data.csv
  session-00-introduction/environment.yml
  session-00-introduction/env.example

Do not commit secrets. Use env.example for API-key templates, not a real .env.

Large datasets (tens of megabytes and up) are better stored elsewhere and
linked from the Resources page. See the course README.
