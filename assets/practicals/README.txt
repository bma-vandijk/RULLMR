Practical session files
=======================

Drop a file in the folder for that session, then add a labelled link in that
session on schedule.md. The schedule does not list files by itself.

  setup/                  local LLM environment, once for the whole course
  00-introduction/        shared by all three introduction dates
  01-literature/
  02-questions/
  03-data-collection/
  04-analysis/
  05-writing/
  06-peer-review/
  07-grants/

Do not commit secrets. Use env.example for API-key templates, not a real .env.

Publisher PDFs often cannot be posted on this public site. Link to an open
copy or a DOI from the schedule instead of uploading the file.

Large datasets (tens of megabytes and up) are better stored elsewhere and
linked from the schedule. See the course README.
